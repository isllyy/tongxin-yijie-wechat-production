# Source Intake

Use this file when the article starts from links, screenshots, pasted notes, or mixed raw materials.

## Source Types

Common inputs:

- WeChat article links
- news links
- screenshots
- draft markdown
- local notes
- prior published `通信伊姐` articles

## Intake Rules

### Links

When the user provides a URL:

1. fetch it first
2. clean it into usable notes
3. separate facts from page clutter

Preferred tool:

- `qiaomu-markdown-proxy`

If the source is WeChat, expect video-widget residue, repeated paragraphs, or image placeholders. Clean these before drafting.

### Screenshots

Treat screenshots as evidence, not as the article itself.

Extract:

- visible labels
- workflow steps
- interface evidence
- dates or signals

Do not overstate anything that the screenshot does not clearly show.

### Existing Drafts

If the user already has `article.md`, revise from the draft instead of restarting from zero.

### Prior Articles

When a new piece is clearly a sequel, read the prior article and reuse:

- core framing
- vocabulary
- follow-up logic

Do not repeat the previous article's whole argument.

## Intake Output

Before drafting, condense materials into:

- source facts
- open questions
- usable screenshots
- supporting links that can stay as references
- risky links that should not appear in the body
