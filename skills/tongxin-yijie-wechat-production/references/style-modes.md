# Style Modes

Use this file to decide how aggressive or emotional the writing should feel inside the Tongxin Yijie workflow.

## Default mode

Use this when the user does not ask for a stronger style.

Characteristics:

- practical
- warm
- readable
- grounded in real work
- understandable to ordinary readers

Best for:

- tool walkthroughs
- workflow reviews
- learning-path articles
- reflection pieces that should still feel stable and trustworthy

## Mimeng-assisted light mode

Use this when the user wants stronger readability and stronger opening force, but the account still needs restraint.

Apply:

- better contradiction in the title
- faster opening
- clearer stance in the first screen
- more memorable closing line

Do not apply:

- excessive rage
- theatrical overstatement
- fake conflict not supported by the material

## Mimeng-assisted strong mode

Use this only when the user clearly wants a higher-voltage article.

Apply:

- stronger title package
- stronger emotional framing
- sharper judgment
- more visible escalation through the body

Always keep these limits:

- facts must remain true
- the article must still feel like Tongxin Yijie, not a copied persona
- if the material is mainly practical, return to light mode or default mode

## Cross-platform mode

When the user wants the same topic rewritten for multiple platforms:

1. build the core judgment with `mimeng-writing`
2. generate WeChat, podcast, and Xiaohongshu versions
3. keep the WeChat version aligned with Tongxin Yijie defaults
4. preserve one shared message across all versions

## Quick selection rule

- no explicit style request -> default mode
- stronger hook, stronger title, but still brand-safe -> Mimeng-assisted light mode
- explicit request for Mimeng-like pull or explosive readability -> Mimeng-assisted strong mode
- multi-platform comparison -> cross-platform mode
