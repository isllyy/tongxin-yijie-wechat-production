# Methodology Stack

Use this file to combine four layers inside the Tongxin Yijie workflow:

1. Khazix-style public-account methodology as the base
2. Tongxin Yijie account defaults as the brand layer
3. WeChat compliance gate as the platform layer
4. Mimeng-assisted writing as the amplification layer

The point is not to copy anyone's persona. The point is to separate:

- how to judge a topic
- how to protect real human material
- how to stay inside platform rules
- how hard to push the emotional and title layer

## Layer 1: Khazix-style base method

Borrow these ideas as the baseline writing discipline:

### HKR topic gate

Before writing, test the topic against three checks:

- H: is it interesting enough to create curiosity?
- K: does it contain real information value?
- R: does it create emotional recognition?

Strong topics usually hit at least two.
If the topic only has one weak dimension, change the angle before drafting.

### Human-AI boundary

Keep this division clear:

AI is good at:

- finding support and counter-support
- proposing analogies
- extending a chosen structure
- filling background knowledge
- helping reorganize logic

Humans must still own:

- firsthand observation
- real personal experience
- the core angle that makes the article stand up
- true emotional reaction
- empathy that turns data into people

If a paragraph feels clean but bloodless, it usually means the human layer is missing.

### Useful article prototypes

A practical public-account article often belongs to one of these:

- investigation or experiment
- product experience
- phenomenon interpretation
- tool sharing wrapped in story
- methodology sharing

Knowing the prototype early helps decide what kind of evidence and rhythm the article needs.

## Layer 2: Tongxin Yijie brand layer

After the topic and material pass the base method, enforce the account's own defaults:

- brand: `Tongxin Yijie`
- author: `Yishui`
- audience: ordinary readers who want to use AI in real work
- tone: warm, practical, readable, not pretending to be omniscient

This is the layer that keeps the final piece from drifting into someone else's account identity.

## Layer 3: WeChat compliance gate

Before drafting and again before publishing, run the article through `wechat-compliance-checklist.md`.

Fail the draft if it relies on:

- incomplete content plus external next steps
- contact guidance in intro, body, comments, footer, or auto-reply
- product-page / activity-page / registration-page action prompts
- multi-step jumps that move readers toward group chats, private contact, signup, or transactions

This layer has veto power over all other layers.

## Layer 4: Mimeng-assisted amplification

Use `mimeng-writing` only after the first three layers are stable.

Best uses:

- sharpen the title package
- strengthen the first screen
- make the judgment clearer
- make the ending more memorable
- create cross-platform versions for WeChat, podcast, and Xiaohongshu

Do not use it to overwrite the account's core trust tone.

## Quick decision rule

- weak topic -> repair with HKR first
- good topic but risky structure -> fix compliance first
- good topic but flat draft -> strengthen with Mimeng-assisted light mode
- already strong draft, but needs bigger pull -> use Mimeng-assisted strong mode
- user wants account-safe practical writing -> stay with Tongxin defaults

## Default order of operations

1. understand the material
2. run HKR
3. identify what only the human can supply
4. run the WeChat compliance gate
5. draft in Tongxin Yijie mode
6. apply Mimeng-assisted strengthening only if needed
7. preview, re-check compliance, polish, and publish
