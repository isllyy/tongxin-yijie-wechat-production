# 标题角度

下表是选择阅读动机的提示，不是固定模板库。每次优先使用文章已经具备的证据；没有证据的角度可以放弃。

| 角度 | 读者为什么愿意读 | 适用材料 |
|---|---|---|
| 具体困扰 | 这正是我遇到的问题 | 用户问题与可执行办法 |
| 完成任务 | 我想知道怎么把事情做完 | 操作步骤、产物或实测过程 |
| 产品变化 | 我使用的东西发生了变化 | 产品或服务的明确改动 |
| 处境代入 | 这个场景与我的工作生活有关 | 身份、地点、动作与真实问题 |
| 预期变化 | 实际情况和常见看法不同 | 可支撑不同判断的案例或证据 |
| 看得见的过程 | 我想看看具体发生了什么 | 操作、制作或服务场景 |
| 值得回答的问题 | 我还不知道这个问题的答案 | 正文能够回答的具体疑问 |
| 理解原因 | 我想看懂现象如何形成 | 原因分析或运作过程 |
| 数字比较 | 我想知道差距和成本在哪里 | 有来源且基准一致的数字 |
| 经验发现 | 别人的真实尝试能帮我判断 | 作者已经发生的体验 |
| 选择代价 | 我需要决定该怎么做 | 不同做法的价值与限制 |
| 情绪共鸣 | 有人说清了我的感受 | 材料支持的处境和判断 |
| 实际矛盾 | 双方需求难以同时满足 | 存在的利益、成本或选择冲突 |
| 当前事件 | 这件事对现在的我有影响 | 已核验的事件时间和进展 |
| 新发现 | 有新的方法或突破值得了解 | 可追溯来源及适用范围 |
| 原话切入 | 一句真实的话就能说明处境 | 确有出处的对话或用户表达 |

稳妥版把对象与价值说明白；传播版可把真实反差或悬念放前面。先保证标题和正文一致，再调整口语、顺序、节奏与标点。

每条以一种阅读动机为主，最多增加一个辅助钩子。不要堆叠品牌名、极值词或情绪词，也不要给每个标题硬塞数字。
